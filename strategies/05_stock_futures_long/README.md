## 一、策略核心哲學與股票期貨交易優勢
股票期貨（個股期）為台股量化多方波段操作效率最高之交易工具：
1. **極致資金槓桿效率**：
   - 一口股票期貨表彰 **2 張現貨 (2,000 股)**。
   - 原始保證金僅需現值之 **約 13.5% ~ 20.25%**（約現貨 1/7 資金成本），資金周轉率提升近 7 倍！
2. **交易稅金極度低廉**：
   - 股票現貨證券交易稅為 **千分之三 (0.3%)**。
   - 股票期貨期交稅僅 **十萬分之二 (0.002%)**，交易摩擦成本大幅降低 **150 倍**！
3. **無融資利息與停券困擾**：
   - 現貨融資需承擔約 6%~7% 年化利息；股票期貨為保證金交易，無利息負擔。
   - 杜絕股東常會、除權息停資停券或券源不足問題。
4. **流動性與防詐防守**：
   - 本策略全面限定臺灣期貨交易所 (TAIFEX) 正式公告之 252 檔個股期貨母池。
   - 5 日均量需達 1,000 張以上，並結合近月期貨未平倉量 (OI) 深度評分，徹底過濾流動性枯竭或易遭操控之小型投機股。

## 二、4+1 核心維度選股濾網 (Hard Filters <= 5)

本策略恪守 4+1 萬用維度標準骨架，嚴格杜絕過度擬合與同質指標疊加：

| 維度編號 | 核心維度 | 實戰量化篩選條件 | 設計邏輯與風控防守目的 |
| :--- | :--- | :--- | :--- |
| **①** | **母池與流動性防守** | 1. 隸屬期交所 252 檔個股期貨清單<br>2. 5 日平均現貨成交量 $\ge 1,000$ 張 | 確保具備標準股票期貨合約可供建倉，杜絕流動性滑價風險。 |
| **②** | **趨勢位階線** | 1. 收盤價 $\ge 20\text{MA}$ 且月線斜率走揚 ($MA20_t \ge MA20_{t-1}$)<br>2. 收盤價 $\ge 60\text{MA}$ (季線之上) | 鎖定中長線多頭排列強勢股，均線多頭排列助漲。 |
| **③** | **籌碼動能面** | 1. 外資或投信近 3 日累計買超 $\ge 1,000$ 張<br>2. 當日法人合計買超佔比 $\ge 12\%$<br>3. 近 5 日法人累計呈現淨買超 | 主力資金連續吃貨，當日主導控盤拉抬，籌碼沉澱集中。 |
| **④** | **型態防守面** | 當日實體陽線或突破平台，且無長上影線（上影線 $< 0.5 \times \text{實體}$） | 排除衝高爆量假突破出貨之墓碑線，確認買盤真突破。 |
| **⑤** | **空間防追高 (起漲甜蜜點)** | 月線正乖離率介於 $+1.0\%$ 到 $+6.0\%$ ($+1.0\% \le \text{Bias} \le +6.0\%$) | **關鍵黃金窗口**：剛脫離整理平台起漲，拒絕 $+8\%$ 以上無肉追高！ |

## 三、第二階段多方軟評分系統 (100 分制)

未達生死線之特徵轉入評分矩陣，取前 3~6 檔精選標的輸出戰報與 LINE 輪播卡：
1. **法人買超佔比強度 (最高 30 分)**：買超佔比自 12% 起跳，每增加 3% 遞增分數。
2. **量能放大倍數 (最高 20 分)**：當日成交量突破 5 日均量 1.5~2.5 倍者給予高分。
3. **均線完整多頭排列 (最高 15 分)**：現價 $> 20\text{MA} > 60\text{MA}$ 多頭排列。
4. **起漲甜蜜正乖離 (最高 15 分)**：正乖離率落於 $+2.0\% \sim +4.5\%$ 區間者最優。
5. **期貨未平倉量 (OI) 深度加分 (最高 20 分)**：
   - $\text{OI} \ge 10,000$ 口（超旗艦主流）：加 20 分
   - $5,000 \le \text{OI} < 10,000$ 口（重倉主力）：加 16 分
   - $2,000 \le \text{OI} < 5,000$ 口（活躍波段）：加 12 分
   - $1,000 \le \text{OI} < 2,000$ 口（流動性充沛）：加 8 分
   - $300 \le \text{OI} < 1,000$ 口（常規合約）：加 4 分
   - $\text{OI} < 300$ 口：加 0 分。
6. **隔日沖高頻倒貨風險扣分 (`algo_guards.py`)**：
   - 自動檢測隔日沖券商特徵（凱基台北、富邦虎尾、美商高盛等）。
   - 若觸發高集中度倒貨警報，自動扣 5~15 分並於戰報標註 `⚠️隔日沖高集中`，提醒次日開盤防開高倒貨、嚴禁無腦追高。

## 四、實戰四大防線定價標準 (Four-Price Standard V4.0)

本策略全面採用根目錄之 [`four_price_engine.py`](file:///four_price_engine.py)，保證幾何單調性與法定檔位精確合規：

$$\text{LimitDown} \le \text{SL} < \text{Close} \le \text{Entry} < \text{Addon} < \text{TP1} \le \text{TP2} \le \text{LimitUp}$$

| 防線標籤 | 實戰點位設定邏輯 | 盤中操盤執行手冊 |
| :--- | :--- | :--- |
| 🟢 **多單進場 (Entry)** | 現價上緣合規檔位上限（換算期貨合約價） | 建議買進上限，現價至此價格區間皆為起漲甜蜜買點，超過嚴禁追價！ |
| 🔵 **動能加碼 (Add-on)** | 突破當日高點 1 檔或進場價 $+2\% \sim +3\%$ | 右側動能確認，放量創日高時執行順勢加碼，擴大波段獲利。 |
| 🔴 **目標停利 TP1** | ATR 波動調校與大盤自適應目標 ($+3.5\% \sim +7.0\%$) | 首波短波段滿足點，分批獲利平倉 $1/3 \sim 1/2$，確保利潤入袋並啟動保本防守。 |
| 🔴 **波段停利 TP2** | 主升段等幅滿足區 ($+6.0\% \sim +15.0\%$) | 主升段極致滿足點，全數獲利平倉出場，滿載獲利而歸。 |
| 🛑 **嚴格停損 (Stop-Loss)** | 跌破 $20\text{MA} - 1.5\%$ 或低點 99 折（最大風控閥 $\le -7.0\%$） | **無條件生命線**：跌破關鍵防守線立即市價平倉，嚴禁凹單死抗！ |

## 五、期貨結算週期戰情與次月新倉開倉規則

依期交所規定，股票期貨結算日為每月份**第三個星期三**：
1. **常規交易期 (距結算 $> 5$ 個交易日)**：
   - 優先以「當月主力合約」為交易與四大防線報價基準，流動性最深厚。
2. **次月新倉開倉期 (結算倒數 $\le 5$ 個交易日)**：
   - 盤後日報與盤中雷達自動啟動結算警報：
     `⚠️【期貨結算倒數 N 日】建議新進場部位優先開立「次月新倉 (YYYYMM)」！`
   - **實戰優勢**：
     * 避免進場 1~4 天內即面臨契約到期強制現金結算。
     * 省去結算前手動平倉轉倉之交易稅、手續費與價差磨損。
     * 直接享有長達一個月以上之波段主升段持有時間，波段抱好抱滿！
