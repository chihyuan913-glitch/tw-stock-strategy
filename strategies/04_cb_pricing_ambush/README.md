# 台股選股策略 04：可轉債 (CB) 定價伏擊與區間博弈旗艦策略

本策略專注於台股市場具備高度法規約束力與主力利益傾向的**「可轉換公司債 (CB) 發行事件」**，透過量化模型捕捉**「自宣布發行後至定價日前後」**的洗盤落點，並在轉換價敲定、壓盤任務結束時進場收割波段紅利。

---

## 🎯 策略核心邏輯 (Trading Thesis)

1. **壓低定價的必然性**：
   - 台股轉換價格計算標準：`訂價基準日前 1、3、5 日普通股收盤均價 × 轉換溢價率 (通常 101%~105%)`。
   - 大股東、內部人與特定認購人為使未來獲利最大化，必然在定價日前藉由借券、賣老股、壓盤不拉抬，將股價壓制在相對低檔。
2. **壓盤解除與競拍造勢**：
   - 轉換價格白紙黑字公告後，主力的「打壓任務」瞬間終結，空單回補、買盤回流。
   - 為求 CB 競拍高價得標或特定人繳款順利，主力有強烈動機將股價維持在轉換價格之上，形成高勝率反彈波段。
3. **強制退場保護（防轉股拋售）**：
   - 掛牌後享有 **3 個月閉鎖期**（不可轉股）。
   - **一旦滿 3 個月閉鎖期解禁**，CB 持有人可隨時將債券轉成現股倒出。因此本策略訂立鐵律：**在閉鎖期解禁日（最後執行日期）前無論賺賠全數清倉！**

## 🎯 操盤四大價位原則 (Four-Price Standard)

依據最高指揮中心規範，每檔個股一律強制提供四大防線價位：

1. **🟢 進場價位 (Entry Price)**：
   - **右側確認（已定價）**：回測已公告之轉換價格 $P_{conv} \sim P$ 區間分批買進 30%。
   - **左側伏擊（生效中）**：回測上升中的 60MA 季線或 $P_0 \times (0.85 \sim 0.88)$ 買進 30%。
2. **🔵 加碼價位 (Add-on Price)**：
   - 帶量突破 5 日線、或突破定價週高點之價位，加碼 70% 完成建倉。
3. **🔴 停利目標 (Take-Profit: TP1 / TP2)**：
   - **TP1 (第一目標)**：公告轉換價上方 $+6\% \sim +8\%$，短線阻力先出 1/3 ~ 1/2。
   - **TP2 (第二目標)**：宣告日前高或波段頸線（約 $+14\% \sim +16\%$），再獲利了結 1/3。
4. **🛑 停損防守 (Stop-Loss Price)**：
   - 跌破轉換價 $4\%$ 或跌破 60MA 季線 $4\%$，無條件認賠退場。

## ⏳ 個股最後執行日期死線 (Exit Deadline) 規範

每檔個股推播必須強制揭露「最後執行死線」，嚴守以下兩大極限：

1. **時間極限 (Time Limit)**：
   - **掛牌日起算滿 3 個月閉鎖期解禁當日**。
   - 說明：CB 自解禁日開始隨時可轉成股票拋售，原策略紅利徹底結束，**不論賺賠強制全數清倉！**
2. **空間極限 (Price Limit)**：
   - **股價觸及轉換價格之 130%**。
   - 說明：連續達標將觸發公司收回條款，主力逼轉目標達成，隨時可能反手出貨，立即停利出場！

## 💻 快速執行教學

### 1. 執行盤後選股與 LINE 推播
```powershell
# 執行選股並發送至 LINE 推播 (策略代號 04)
python screener.py --line --export result.csv

# 僅產出報表
python screener.py --export result.csv
```

### 2. 啟動盤中即時到價雷達 (09:00 ~ 13:35 每 3 分鐘自動巡邏)
```powershell
# 手動啟動即時雷達
python intraday_scanner.py

# 或直接雙擊批次檔
start_intraday.bat
```

### 3. 每日自動排程批次檔
直接點擊執行 `run_daily.bat`，或由根目錄 `run_all.py` / Windows 工作排程器統一調度。
