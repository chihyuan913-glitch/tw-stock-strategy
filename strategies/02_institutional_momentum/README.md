# 台股策略 02：法人籌碼集中起漲選股策略 (主升段動能版)

本策略專注於捕捉「外資與投信主力大額買超吃貨、月線上揚助漲、未追高乖離適中」的高勝率波段起漲黑馬股。

---

## 核心選股與風控條件

1. **流動性防守**：近 5 日平均成交量 $\ge 1,000$ 張，排除流動性陷阱與冷門股。
2. **籌碼主力吃貨**：
   - 外資或投信近 3 個交易日累計買超 $\ge 1,000$ 張。
   - 法人買超張數佔當日成交量 $\ge 10\%$（主力資金主導）。
   - 近 5 日主力籌碼呈現淨買超且籌碼集中。
3. **技術面助漲趨勢**：
   - 收盤價站穩 20MA（月線），且月線斜率維持向上 ($MA20_t > MA20_{t-1}$)。
4. **起漲防追高濾網**：
   - 股價與月線正乖離率 $< 8\%$（嚴守起漲安全區，不追高）。
   - 當日 K 線無爆量長上影線（上影線長度 $<$ 實體 K 棒的一半），排除假突破出貨。
5. **操盤四大實戰價位**：
   - 進場價：現價建倉。
   - 加碼價：突破昨日或今日高點。
   - 停利價：TP1 (+8%~10%), TP2 (+15%~20%)。
   - 停損價：跌破月線或成本 -3%~-5% 嚴格停損。

## 目錄檔案結構

```text
strategies/02_institutional_momentum/
├── screener.py          # 盤後自動化選股器 (支援 --line 與 --export)
├── intraday_scanner.py  # 盤中即時雷達 (09:00~13:35 巡邏推播)
├── run_daily.bat        # 盤後手動執行批次檔
├── start_intraday.bat   # 盤中手動一鍵啟動雷達批次檔
├── result.csv           # 最新選股清單報表 (UTF-8-BOM)
├── result.md            # Markdown 格式戰報
├── README.md            # 本手冊
└── legacy/              # 歷史 XQ 與 TradingView 腳本封存
```

---

## 快速使用指令

```powershell
# 執行盤後選股並匯出報表
python screener.py --export result.csv

# 執行盤後選股並即時推播至 LINE
python screener.py --line --export result.csv

# 啟動盤中即時巡邏雷達 (每 60 秒)
python intraday_scanner.py --interval 60
```
