# 台股策略 02：法人籌碼集中起漲選股策略 (回測驗證旗艦版)

本策略專注於捕捉「外資與投信主力大額買超吃貨、大盤多頭順風助漲、月線上揚、未追高乖離適中」的高勝率波段起漲黑馬股。
本策略於民國 114 年 1 月 1 日至 115 年 9 月 30 日（2025-01-01 ～ 2026-09-30，共 21 個月、422 個交易日）完成全市場真實數據回測驗證：**累積報酬率 +67.06%（年化 CAGR +35.53%），勝率 48.7%，獲利因子 2.37，最大回撤僅 -4.60%，夏普比率 2.45**。

---

## 核心選股與優化進退場條件

### 一、進場條件 (Entry Checklist)
1. **大盤環境順風濾網 (Market Regime Filter)**：
   - 台灣加權指數 (^TWII) 站在月線（20MA）之上，大盤多頭確立始建倉；大盤破月線時全數觀望，避開系統性黑天鵝。
2. **流動性防守**：
   - 近 5 日平均成交量 $\ge 1,000$ 張，嚴格排除 00 開頭 ETF、全額交割股與流動性枯竭標的。
3. **籌碼主力大額吃貨**：
   - 外資或投信近 3 個交易日累計淨買超 $\ge 1,000$ 張。
   - 法人當日淨買超佔當日成交量 $\ge 10\%$（主力資金定價權）。
   - 近 5 日三大法人合計淨買超 $> 0$（主力籌碼持續集中吸納）。
4. **技術面助漲結構**：
   - 收盤價站穩 20MA（月線），且月線斜率維持向上 ($MA20_t > MA20_{t-1}$)。
5. **起漲甜蜜防追高濾網**：
   - 股價與月線正乖離率介於 $0\% \le Bias < 8\%$（嚴守起跑線甜密區，不追高）。
   - 當日 K 棒上影線長度 $<$ 實體 K 棒的一半，排除爆量出貨假突破。

---

### 二、操盤四大實戰價位與出場機制 (Exit SOP)
1. **🟢 進場價位 (Entry Price)**：
   - 盤後篩選確定，次日開盤價（Next-day Open）進場建倉。
2. **🔵 加碼價位 (Add-on Price)**：
   - 突破昨日高點且大盤續強時，可順勢加碼 1 次。
3. **🔴 停利價位 (Take-Profit Price)**：
   - **第一停利 TP1 (+15%)**：現價觸及進場價 $+15\%$ 時，**獲利了結 50% 部位**，同時將剩餘部位停損位上移至成本保本價（Break-even）。
   - **第二停利 TP2 (+20%)**：續強攻抵 $+20\%$ 全數出場；或以 **10 日均線（10MA）作為波段移動停利線**（未破續抱，跌破收盤平倉）。
4. **🛑 停損價位 (Stop-Loss Price)**：
   - **收盤波段停損**：13:30 收盤價有效跌破 **月線 2% ($MA20 \times 0.98$)**，次日開盤平倉離場（避免盤中短線開盤毛刺甩轎）。
   - **盤中絕對硬停損**：盤中現價跌破進場成本 **-5.0%**，立即強制停損防範跳空黑天鵝。
5. **時間停損 (Time Exit)**：
   - 持有滿 30 個交易日若未達停利亦未達停損，強制平倉釋放資金。

## 目錄檔案結構

```text
strategies/02_institutional_momentum/
├── screener.py                          # 盤後自動化選股器 (支援 --line 與 --export)

├── backtest_report_114_115.md           # 114~115 年完整回測研究戰報

├── backtest_monthly_returns_optimized.csv # 季度與月度報酬統計
├── run_daily.bat                        # 盤後手動執行批次檔
├── start_intraday.bat                   # 盤中手動一鍵啟動雷達批次檔
├── result.csv                           # 最新選股清單報表 (UTF-8-BOM)
└── README.md                            # 本策略操作與回測手冊
```

## 快速使用指令

```powershell
# 執行盤後選股並匯出報表
python screener.py --export result.csv

# 執行盤後選股並即時推播至 LINE
python screener.py --line --export result.csv

# 重新運行 114~115 年完整回測驗證
python backtest_engine.py

# 啟動盤中即時巡邏雷達 (每 60 秒)
python intraday_scanner.py --interval 60
```
