# 策略 06：盤中成交量異常爆量起漲動能監控告警 (Strategy 06: Volume Surge Momentum Radar V2.0)

## 一、策略核心哲學 (Core Philosophy)
在台股實戰操盤中，「量是價的先行指標」。當主力大戶、外資投信或市場活躍游資發動一檔個股時，往往在盤中第一時間引爆**「時間加權動態異常爆量」**。
本策略聚焦捕捉：**主力資金強勢點火、量能突破動能布林軌（+3σ）、且股價呈現高勝率實體紅K起漲之初升段/主升段飆股**。

V2.0 旗艦版深度升級四大核心能力：
1. **全域自適應市場位階連動 (`adaptive_regime_manager.py`)**：隨大盤多空狀態自動調整爆量門檻、乖離防追高安全閥與 TP1/TP2 停利目標。
2. **法人吃貨鎖碼純度評估 (Institutional Volume Quality Index)**：精算籌碼吸收率，嚴辨「良性換手鎖碼」vs「主力倒貨散戶接刀陷阱」。
3. **機構級非線性時段加權量能模型 (TWSE Empirical Time-Weighted Volume Curve)**：根除早盤前 30 分鐘線性除法之虛假爆量毛刺。
4. **盤中高水位動態移動停利 (High-Water Mark Trailing Stop Alert)**：波段獲利達標後動態跟隨最高價，鎖死主升段戰果。

## 二、4+1 維度硬性篩選鐵律 (Hard Filters)
依據《台股選股策略 總指揮中心規範》第四條，硬性篩選條件嚴禁超過 5 個，杜絕過度擬合：

| 維度 | 規則名稱 | 篩選條件門檻 | 實戰目的 |
| :--- | :--- | :--- | :--- |
| **① 流動性防守** | 基礎流動性門檻 | 5日移動平均成交量 $\ge 1,000$ 張，排除全額交割、處置股與 DR 股 | 杜絕流動性陷阱與無量滑價風險 |
| **② 趨勢位階線** | 月線多頭支撐線 | 收盤價 $\ge 20\text{MA}$ 且 $20\text{MA}$ 斜率持平或向上 | 確保處於多方控盤結構，不在空頭破線股做多 |
| **③ 爆量突破動能** | 動態量能突破軌 | 當日量比 $R_{\text{vol}} \ge \text{Adaptive Threshold}$ (基準 $2.2\times \sim 2.5\times$) | 捕捉主力資金急劇湧入之起漲動能 |
| **④ 型態防守面** | 實體飽滿紅K棒 | 當日漲幅 $\ge +2.0\%$ 且 實體比例 $\frac{\text{Close} - \text{Low}}{\text{High} - \text{Low}} \ge 0.60$ | 嚴禁長上影線（$<40\%$），徹底排除爆量出貨線 |
| **⑤ 空間防追高** | 月線乖離安全區 | 收盤價與 20MA 正乖離率 $< \text{Adaptive Bias Limit}$ (基準 $3.5\% \sim 9.2\%$) | 確保於起漲初期介入，防止高檔接刀吃回檔 |

## 三、第二階段軟評分與法人吃貨鎖碼純度 (Volume Quality Matrix)
通過硬篩後之標的，進入第二階段量化評分（滿分 100 分），排序推播前 3~8 檔精華：

1. **爆量強度分 ($0 \sim 35$ 分)**：
   - $R_{\text{vol}} \ge 4.0$ 倍：**+35 分**（極致天量主升）
   - $R_{\text{vol}} \ge 3.0$ 倍：**+25 分**（強烈攻擊量）
   - $R_{\text{vol}} \ge 2.5$ 倍：**+15 分**（初段異常量）
2. **K 線實體強度分 ($0 \sim 25$ 分)**：
   - 實體比例 $\ge 0.85$（光頭大陽線）：**+25 分**
   - 實體比例 $\ge 0.70$：**+15 分**
3. **法人吃貨鎖碼純度評估 ($0 \sim 20$ 分 + 品質標籤)**：
   - **籌碼吸收率**：$\text{Absorption Ratio} = \frac{\text{外資淨買} + \text{投信淨買}}{\text{當日總成交量}} \times 100\%$
   - 🟢 **法人吃貨鎖碼 (+20分)**：法人合計買超 $\ge 1,000$ 張且吸收率 $\ge 12\%$，籌碼被大戶大量收走。
   - 🟢 **法人大額買超 (+18分)**：法人買超 $\ge 1,000$ 張。
   - 🔵 **法人溫和吃貨 (+15分)**：法人買超 $\ge 500$ 張。
   - ⚖️ **良性換手整理 (+5分)**：法人小買且吸收率 $\le 10\%$，市場籌碼健康換手。
   - ⚠️ **主力調節倒貨 (-5分)**：法人合計賣超 $\le -250$ 張或吸收率 $\le -5\%$，嚴防散戶追高出貨。
4. **基礎自適應權重 (20 分)**
5. **程式交易反制扣分 (`algo_guards.py`)**：
   - 隔日沖分點扎堆或自營商避險爆量：**扣 10 ~ 15 分**，並標註 `⚠️隔日沖警戒`。

## 四、實戰操盤四大防線價位標準 (Four-Price Defense)
所有推播一律強制提供精確點位指引，並恪守數學單調性：
$$\text{sl\_price} < \text{current\_price} \le \text{entry\_price} < \text{addon\_price} < \text{tp1\_price} < \text{tp2\_price}$$

- 🟢 **建議進場價 (Entry Price)**：
  - 盤中爆量觸發點位或收盤價 $+1.0\%$ 為買進上限（防追高無肉）。
- 🔵 **動能加碼價 (Add-on Price)**：
  - 突破當日最高價 $+0.5\%$ 帶量續攻確認點。
- 🔴 **停利目標價 (Take-Profit Price)**：
  - **TP1 (第一目標)**：進場價 $+ \text{Adaptive TP1}$ ($+4.0\% \sim +9.6\%$)，分批拔檔。
  - **TP2 (第二目標)**：進場價 $+ \text{Adaptive TP2}$ ($+7.0\% \sim +15.0\%$)，主升段滿足區。
- 🛑 **嚴格停損價 (Stop-Loss Price)**：
  - 跌破當日爆量起漲紅K最低價，或跌破進場成本 $-3.5\% \sim -5.0\%$（取較高者作為不可退縮防線）。

## 五、盤中到價雷達、非線性模型與動態移動停利 (Intraday Radar)

### 1. 機構級非線性時段加權量能模型
台股開盤 09:00~13:30（共 270 分鐘），成交量分佈高度集中於早盤與尾盤。線性模型在 09:10 容易因除以極小分母而虛報天量。
V2.0 採用四段非線性時段曲線：
- **09:00 ~ 09:13.5**：$P_t = 0.05$（鎖定平滑防呆下限，防早盤高頻毛刺）。
- **09:13.5 ~ 09:30**：$P_t$ 自 $0.05$ 快速非線性攀升至 $0.18$（反映早盤搶買大潮）。
- **09:30 ~ 12:00**：$P_t$ 自 $0.18$ 線性穩定延伸至 $0.70$（盤中中段平滑過渡）。
- **12:00 ~ 13:30**：$P_t$ 自 $0.70$ 升至 $1.00$（尾盤收盤）。

### 2. 盤中高水位動態移動停利引擎 (High-Water Mark Trailing Stop)
- **啟動條件**：盤中自進場成本/開盤價起算，最大波段獲利 $\ge +4.5\%$（自適應可調）。
- **回撤警報**：現價自當日盤中最高價（HWM）拉回回吐 $\ge 2.0\%$，且通過 `GLOBAL_TICK_GUARD` 防毛刺守門。
- **推播規格**：派發【🔒 高檔回馬槍・移動停利保全獲利】紫底徽章 Flex 卡片，提醒分批獲利收網，杜絕坐雲霄飛車獲利變虧損。

### 3. 階梯式防洗版去重狀態機
- 階段一（初段爆量）：$R_{\text{vol}} \ge 2.2\times$ 且當日未觸發，發送【🚨 初段異常爆量起漲】戰訊卡。
- 階段二（天量噴出）：$R_{\text{vol}} \ge 4.0\times$ 且未發送過次段，發送【🔥 極致天量主升噴出】戰訊卡。
- 移動停利（高檔回馬槍）：單檔股票當日觸發後加入抑制集合，不重複洗版。
