# 策略 06：盤中成交量異常爆量起漲動能監控告警 (Strategy 06: Volume Surge Momentum Radar)

## 一、策略核心哲學 (Core Philosophy)
在台股實戰操盤中，「量是價的先行指標」。當主力大戶、外資投信或市場活躍游資發動一檔個股時，往往在盤中第一時間引爆**「時間加權動態異常爆量」**。
本策略聚焦捕捉：**主力資金強勢點火、量能突破動能布林軌（+3σ）、且股價呈現高勝率實體紅K起漲之初升段/主升段飆股**。

同時，為反制高頻量化程式單與隔日沖倒貨假出量，策略全面強制結合：
1. **動態量能布林通道突破**（排除自然背景常態量）。
2. **實體紅棒檢驗**（排除主力拉高出貨爆量長上影線墓碑線）。
3. **`algo_guards.py` 隔日沖分點與防毛刺守門**（排除券商避險與 1-tick 瞬間假突破甩轎）。

## 二、4+1 維度硬性篩選鐵律 (Hard Filters)
依據《台股選股策略 總指揮中心規範》第九條，硬性篩選條件嚴禁超過 5 個：

| 維度 | 規則名稱 | 篩選條件門檻 | 實戰目的 |
| :--- | :--- | :--- | :--- |
| **① 流動性防守** | 基礎流動性門檻 | 5日移動平均成交量 $\ge 1,000$ 張，排除全額交割、處置股與 DR 股 | 杜絕流動性陷阱與無量滑價風險 |
| **② 趨勢位階線** | 月線多頭支撐線 | 收盤價 $\ge 20\text{MA}$ 且 $20\text{MA}$ 斜率持平或向上 | 確保處於多方控盤結構，不在空頭破線股做多 |
| **③ 爆量突破動能** | 動態量能突破軌 | 當日成交量 $\ge 2.5 \times 5\text{MA}$ 均量（或盤中動態預估量比 $R_{\text{vol}} \ge 2.5$） | 捕捉主力主力資金急劇湧入之起漲動能 |
| **④ 型態防守面** | 實體飽滿紅K棒 | 當日漲幅 $\ge +2.0\%$ 且 實體比例 $\frac{\text{Close} - \text{Low}}{\text{High} - \text{Low}} \ge 0.60$ | 嚴禁長上影線（$<40\%$），徹底排除爆量出貨線 |
| **⑤ 空間防追高** | 月線乖離安全區 | 收盤價與 20MA 正乖離率 $< 10\%$ | 確保於起漲初期或均線剛帶量突破時介入，防止短線過度追高 |

## 三、第二階段軟評分矩陣 (Soft Scoring Matrix)
通過硬篩後之標的，進入第二階段量化評分（滿分 100 分），排序推播前 3~8 檔精華：

1. **爆量強度分 ($0 \sim 35$ 分)**：
   - $R_{\text{vol}} \ge 4.0$ 倍：**+35 分**（極致天量主升）
   - $R_{\text{vol}} \ge 3.0$ 倍：**+25 分**（強烈攻擊量）
   - $R_{\text{vol}} \ge 2.5$ 倍：**+15 分**（初段異常量）
2. **K 線實體強度分 ($0 \sim 25$ 分)**：
   - 實體比例 $\ge 0.85$（光頭大陽線）：**+25 分**
   - 實體比例 $\ge 0.70$：**+15 分**
3. **法人同買動能分 ($0 \sim 20$ 分)**：
   - 外資或投信當日大額買超 $\ge 1,000$ 張：**+20 分**
   - 外資或投信買超 $\ge 500$ 張：**+10 分**
4. **籌碼集中與週轉分 ($0 \sim 20$ 分)**：
   - 當日週轉率介於 $5\% \sim 18\%$ 之健康換手區間：**+20 分**
5. **風控扣分懲罰項 (`algo_guards.py`)**：
   - 隔日沖分點高度扎堆或自營商避險爆量：**扣 10 ~ 15 分**，並標註 `⚠️隔日沖警戒`。

## 四、實戰操盤四大防線價位標準 (Four-Price Defense)
所有推播一律強制提供精確點位指引：

- 🟢 **建議進場價 (Entry Price)**：
  - 盤中爆量觸發點位或收盤價 $+1.0\%$ 為買進上限（防追高無肉）。
- 🔵 **動能加碼價 (Add-on Price)**：
  - 突破當日盤中最高價（或前高）$+0.5\%$ 帶量續攻確認點。
- 🔴 **停利目標價 (Take-Profit Price)**：
  - **TP1 (第一目標)**：進場價 $+8\%$，短線急拉拔檔減碼 1/3 ~ 1/2。
  - **TP2 (第二目標)**：進場價 $+15\%$ 或前波波段歷史高點，波段主升段滿足區。
- 🛑 **嚴格停損價 (Stop-Loss Price)**：
  - 跌破當日爆量起漲紅K最低價，或跌破進場成本 $-3.5\%$（取較高者作為不可退縮防線）。

## 五、盤中到價雷達與雙層防限流架構 (Intraday Scanner)
1. **雙層低頻請求 (Two-Layer API Fetcher)**：
   - **Layer 1**：單次 HTTP 抓取證交所/櫃買當日盤中成交量排行（約 100~200 檔活躍榜），1 次 API 搞定全市場熱點。
   - **Layer 2**：結合 `result.csv` 與 `watchlist.json` 核心池，全池去重後約 80~120 檔，批量更新極速且零封鎖風險。
2. **時間加權動態預估量比 ($P_t$ Paced Ratio)**：
   - 開盤分鐘數 $T$（09:00~13:30，共 270 分鐘）。
   - 進度比例 $P_t = \max(0.05, T / 270)$。
   - 全日動態預估量 $V_{\text{est}} = V_{\text{current}} / P_t$。
   - 量比 $R_{\text{vol}} = V_{\text{est}} / V_{\text{5MA}}$。
3. **階梯式防洗版去重狀態機 (Stepped Deduplication)**：
   - 階段一（初段爆量）：$R_{\text{vol}} \ge 2.5\times$ 且當日未觸發，發送【🚨 初段異常爆量起漲】Flex 戰訊卡。
   - 階段二（天量噴出）：$R_{\text{vol}} \ge 4.0\times$ 且未發送過次段，發送【🔥 極致天量主升噴出】Flex 戰訊卡。
   - 單檔股票當日最多推播 2 次，徹底根除洗版！
