# 台股策略 03：弱勢破線做空與股票期貨避險策略

本策略專注於捕捉「外資與投信主力大額倒貨提款、跌破月線下彎、具備股票期貨標的」之弱勢空方破底股，提供避險保值與順勢放空之量化依據。

---

## 核心選股與風控條件

1. **全面鎖定期交所股票期貨標的**：
   - 內建 `stock_futures_list.json` 連動期交所名單。
   - **實戰優勢**：做空免借券、無融券限額、免除股東會/除權息強制回補、期交稅僅十萬分之二 (0.002%)。
2. **籌碼主力倒貨出貨**：
   - 外資或投信近 3 個交易日累計賣超 $\ge 1,000$ 張。
   - 法人賣超張數佔當日成交量 $\ge 10\%$（賣方資金主導砸盤）。
   - 近 5 日法人籌碼呈現淨賣超。
3. **空頭趨勢確認**：
   - 收盤價跌破 20MA（月線），且月線斜率向下 ($MA20_t < MA20_{t-1}$，均線反壓助跌)。
   - 近 5 日平均成交量 $\ge 1,000$ 張，確保流動性。
4. **防軋空起跌安全濾網**：
   - 月線負乖離率介於 $[-8.0\%, 0\%]$（剛破線起跌區，避免在超跌處追空被軋反彈）。
   - 當日 K 線無長下影線（排除低檔有主力強撐的假破線）。
5. **操盤四大實戰價位**：
   - 空單進場：現價或反彈至月線反壓處佈空。
   - 加空價位：跌破今日低點續跌確認。
   - 停利回補：TP1 負乖離 -12% ｜ TP2 負乖離 -20%。
   - 停損回補：站回月線反壓或成本 +2% 嚴格無條件停損！

## 目錄檔案結構

```text
strategies/03_short_momentum/
├── screener.py          # 盤後放空選股器 (支援 --line 與 --export)
├── intraday_scanner.py  # 盤中到價即時雷達與推播系統 (支援 --line 與四大價位比對)
├── start_intraday.bat   # 一鍵啟動盤中到價即時雷達
├── stock_futures_list.json # 期交所股票期貨標的對應庫
├── run_daily.bat        # 盤後手動執行批次檔
├── result.csv           # 最新選股清單報表 (UTF-8-BOM)
├── result.md            # Markdown 格式戰報
├── README.md            # 本手冊
└── legacy/              # 歷史 XQ 與 TradingView 腳本封存
```

## 快速使用指令

```powershell
# 執行盤後選股並匯出報表
python screener.py --export result.csv

# 執行盤後選股並即時推播至 LINE (策略03群組)
python screener.py --line --export result.csv

# 啟動盤中做空到價即時雷達 (每 60 秒巡邏)
python intraday_scanner.py --interval 60

# 測試盤中做空到價推播 (發送模擬到價快訊至 LINE)
python intraday_scanner.py --test-push
```
