# 台股策略 03：弱勢破線做空與股票期貨避險策略 V3.0 (全域旗艦版)

本策略專注於捕捉「外資與投信主力大額倒貨提款、跌破月線下彎、限定臺灣期交所股票期貨標的」之弱勢空方破底股，提供避險保值與順勢放空之量化操盤依據。

基於歷史量化回測數據與全專案總指揮中心規範，V3.0 全面導入**「實戰四大防線定價引擎 V4.0」**、**「期貨未平倉量 (OI) 深度流動性防守」**、**「期貨結算倒數 5 日開次月新倉標準」**與**「雙層降級容錯架構」**。

---

## 🎯 核心選股與優化進出場條件 (V3.0 規範)

### 1. 宏觀市場環境與自適應大盤紅綠燈：
- **動態載入全域自適應市場位階設定 (`adaptive_regime_manager.py`)**：
  - 🟣 **放空避險黃金期 (BEAR_DEFENSIVE)**：加權指數跌破 20MA 或 20MA 斜率下彎，做空勝率與期望值處於黃金期。
  - 🟡 **箱型震盪輪動 (SIDEWAYS_CONSOLIDATION)**：個股走勢分化，放空聚焦於弱勢破線股。
  - 🔴 **高檔過熱警戒 (BULL_OVERHEAT)**：慎防主力波段獲利了結倒貨，空單小量佈局。
  - ⚠️ **多頭強勢攻堅 (BULL_MOMENTUM)**：多頭均線向上助漲，系統強烈警示逆勢做空風險，僅供現貨多單對沖避險。
- 支援 `--hedge-only` 嚴格避險開關（大盤多頭時自動終止開空）。

### 2. 全面鎖定期交所股票期貨標的 (TAIFEX)：
- 內建 `stock_futures_list.json` 連動期交所 254 檔個股期貨名單。
- 排除 ETF（0050、0056）與非個股標的，確保 1 口 = 2 張現貨（2,000 股）精確換算。
- **實戰優勢**：零券源限制、零借券費、免除股東會/除權息強制回補、期交稅僅十萬分之二 (0.002%)，資金槓桿效率高達 7.4 倍。

### 3. 籌碼主力倒貨出貨 (4+1 維度硬性條件)：
- 外資或投信近 3 個交易日累計賣超 $\ge 1,000$ 張 (<-1,000,000 股)。
- **法人賣超張數佔當日成交量 $\ge 12\%$**（鎖定外資/投信主力集中砸盤股）。
- 近 5 日三大法人合計呈現淨賣超。

### 4. 空頭趨勢與起跌甜蜜點：
- 收盤價跌破 20MA（月線），且月線斜率向下 ($MA20_t \le MA20_{t-1}$，均線反壓助跌)。
- 近 5 日平均成交量 $\ge 1,000$ 張，確保進出流動性。
- **起跌甜蜜點收緊：月線負乖離率介於 $[-5.0\%, 0\%]$**（剛破線起跌區，起跌空間最大，徹底杜絕跌深追空被技術性反彈軋空）。
- 當日 K 線無長下影線（下影線長度小於實體一半，排除低檔主力強撐）。

### 5. 雙層降級容錯架構 (Tier-1 / Tier-2)：
- **Tier-1【核心起跌】**：負乖離率 $[-5.0\%, 0\%]$ ＋ 賣超佔比 $\ge 12\%$ ＋ 3日賣超 $\ge 1,000$ 張。
- **Tier-2【破線候補】**：若 Tier-1 通過小於 4 檔，自動啟用 Tier-2 候補（負乖離放寬至 $[-8.0\%, 0\%]$，賣超佔比放寬至 $\ge 8\%$，3日賣超 $\ge 600$ 張），標註 `[Tier-2 破線候補]`，保證避險雷達戰報品質。

### 6. 實戰四大防線定價引擎 V4.0 全域規範：
- 完整引用 `four_price_engine.py` 之 `calculate_four_prices_short()`。
- **臺灣證交所法定 6 階升降檔位方向性合規取整**：
  - 🟢 **建議放空上限 (Entry)**：現價向下合規取整（超過此上限嚴禁追低放空）。
  - 🔵 **摜破加空點 (Add-on)**：摜破關鍵低點向下取整（破線動能追擊）。
  - 🔴 **停利回補點 (TP1 & TP2)**：波段滿足點向上合規取整（有利撮合平倉買回）。
  - 🛑 **嚴格停損價 (Stop-Loss)**：站回月線反壓向上合規取整（防盤中毛刺掃損）。
- 幾何單調性嚴格單向守護：
  $$\text{LimitDown} \le \text{TP2} \le \text{TP1} < \text{Add-on} < \text{Entry} \le \text{Close} < \text{SL} \le \text{LimitUp}$$
- 盈虧比強制檢核：$(\text{Entry} - \text{TP1}) / (\text{SL} - \text{Entry}) \ge 1.5$。

### 7. 期貨未平倉量 (OI) 深度流動性加分與 100 分制軟評分：
- 納入期貨未平倉口數 (OI) 評估：
  - $\ge 10,000$ 口：+20 分（超旗艦主流，滑價風險極低）
  - $\ge 5,000$ 口：+16 分
  - $\ge 2,000$ 口：+12 分
  - $\ge 1,000$ 口：+8 分
  - $< 1,000$ 口：+4 分（冷門合約降級推薦）
- 整合 `algo_guards.py` 隔日沖分點出貨扣分與警示。
- 換算五星級推薦（★★★★★ / ★★★★☆ / ★★★☆☆）並優先排序。

### 8. 期貨結算倒數 5 日開立次月新倉標準：
- 自動計算期交所各交割月份第三個星期三（法定結算日）。
- 距結算日 $\le 5$ 個交易日時，自動於日報、盤中雷達與 LINE 戰訊啟動：
  `⚠️【期貨結算倒數 N 日・建議直接開立次月新倉】`，並同步展示次月合約代碼、次月報價與四大防線。

## 💻 快速使用指令

```powershell
# 執行盤後選股並匯出報表 (預設 V3.0 旗艦參數)
python screener.py --export result.csv

# 執行盤後選股 (啟用嚴格大盤避險模式，多頭時自動攔截)
python screener.py --hedge-only --export result.csv

# 執行盤後選股並即時推播至 LINE (策略 03 獨立群組)
python screener.py --line --export result.csv

# 啟動盤中做空到價即時雷達 (每 60 秒巡邏四大防線到價事件)
python intraday_scanner.py --interval 60

# 測試盤中雷達推播連線與卡片排版
python intraday_scanner.py --test-push
```
