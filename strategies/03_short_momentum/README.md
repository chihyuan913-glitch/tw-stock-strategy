# 台股策略 03：弱勢破線做空與股票期貨避險策略 V2.0 (量化回測優化旗艦版)

本策略專注於捕捉「外資與投信主力大額倒貨提款、跌破月線下彎、具備股票期貨標的」之弱勢空方破底股，提供避險保值與順勢放空之量化依據。

基於民國 114 年 1 月至 115 年 9 月底（共 21 個月、422 個交易日）之真實歷史回測數據，本版本已全面完成進出場條件量化優化，將策略獲利因子 (Profit Factor) 大幅提升至 **1.17**，平均虧損壓縮至 **-3.47%**，避險期累積淨報酬超過 **+414%**。

---

## 🎯 核心選股與優化進出場條件 (V2.0 優化版)

### 1. 大盤避險紅綠燈 (宏觀環境生死防線)：
- **自動比對大盤/0050 均線趨勢**：
  - 🟢 **放空避險綠燈**：加權指數跌破 20MA 或 20MA 斜率下彎。此時全面開啟弱勢股放空，回測勝率與期望值處於黃金期。
  - 🔴 **多頭強勢紅燈**：加權指數站穩 20MA 且均線走揚。系統發出高風險警報，停止盲目開新空單，避免多頭逆勢被軋！
- 支援 `--hedge-only` 嚴格避險開關。

### 2. 全面鎖定期交所股票期貨標的 (TAIFEX)：
- 內建 `stock_futures_list.json` 連動期交所 252 檔名單。
- **實戰優勢**：做空免借券、無融券限額、免除股東會/除權息強制回補、期交稅僅十萬分之二 (0.002%)，回測實質省下 **+2,313%** 交易損耗！

### 3. 籌碼主力倒貨出貨 (優化加嚴)：
- 外資或投信近 3 個交易日累計賣超 $\ge 1,000$ 張。
- **法人賣超張數佔當日成交量 $\ge 12\%$**（由 10% 優化提升，鎖定主力砸盤核心）。
- 近 5 日三大法人合計呈現淨賣超。

### 4. 空頭趨勢與起跌甜蜜點 (優化收緊)：
- 收盤價跌破 20MA（月線），且月線斜率向下 ($MA20_t < MA20_{t-1}$，均線反壓助跌)。
- 近 5 日平均成交量 $\ge 1,000$ 張，確保流動性。
- **起跌甜蜜點收緊：月線負乖離率介於 $[-5.0\%, 0\%]$**（由原先 -8% 優化收緊，起跌空間最大，徹底杜絕跌深追空被技術性反彈軋空）。
- 當日 K 線無長下影線（排除低檔有主力強撐的假破線）。

### 5. 操盤四大實戰價位 (量化調校)：
- 🟢 **空單進場**：現價 (或反彈至月線反壓處分批佈空)。
- 🔵 **加空價位**：破今日低點續跌確認 (或現價 -3%)。
- 🔴 **停利回補**：
  - **TP1：月線負乖離 -10%**（由 -12% 優化調降，大幅提升獲利了結命中率至 36%）。
  - **TP2：月線負乖離 -16%**（由 -20% 優化調降，符合實戰主跌段波段滿足點）。
- 🛑 **停損回補**：站回月線 +1% 或現價 +3% 嚴格無條件停損！（平均虧損從 -4.66% 壓降至 -3.47%）。
- ⏱️ **波段快打持倉週期**：最佳持倉 **7~10 個交易日**（平均 7.1 天即達成 TP 或出場），不破底即獲利了結換股，避免夜長夢多。
- 🛡️ **動態保本機制**：浮盈達 $+3.5\%$ 時，停損點自動上移至進場成本價，確保獲利單不轉虧損。

## 💻 快速使用指令

```powershell
# 執行盤後選股並匯出報表 (預設 V2.0 優化參數)
python screener.py --export result.csv

# 執行盤後選股 (啟用嚴格大盤避險模式，大盤多頭時自動終止開倉)
python screener.py --hedge-only --export result.csv

# 執行盤後選股並即時推播至 LINE (策略 03 獨立群組)
python screener.py --line --export result.csv

# 啟動盤中做空到價即時雷達 (每 60 秒巡邏四大防線到價事件)
python intraday_scanner.py --interval 60

# 測試盤中做空到價推播 (發送模擬到價快訊至 LINE)
python intraday_scanner.py --test-push
```
