# 台股選股策略 V2.5 雙層降級容錯旗艦版：布林通道下軌超跌 ＋ 法人逆勢買超 ＋ 雙層動態候補

本專案為台股量化選股系統之「策略一：布林通道下軌超跌反轉」，整合**統計學波動通道**、**三大法人籌碼純度**與**K線價格型態**，專注於捕捉「散戶恐慌殺低、籌碼落入法人手中、超跌技術性反轉」的高勝率波段進場點。

---

## 策略設計核心架構 (V2.5 升級重點)

### 1. 雙層門檻動態降級容錯架構 (Dual-Tier Fallback)
徹底解決強勢多頭市場或指數盤整期「連續多日選不出個股」之痛點：
- **🟢 Tier-1【布林極致超跌・法人逆勢低接】**：
  - 日成交量 $\ge 1,000$ 張
  - 股價落入布林下軌極致超跌區間：$-5.0\% \le \text{距下軌偏離} \le +1.0\%$
  - 三大法人合計買超佔比 $\ge 1.5\%$ 且 投信無恐慌拋售（賣超 $\le 500$ 張）
  - 20MA 近5日變化率 $\ge -2.5\%$（排除通道向下大開口主跌段）
- **🟡 Tier-2【布林支撐回測・主力防守候補】**：
  - 若 Tier-1 篩選結果為 0 檔，**系統自動無縫啟動 Tier-2 候補機制**。
  - 日成交量放寬至 $\ge 800$ 張
  - 股價位階擴大至下軌上方緩衝區：$-5.0\% \le \text{距下軌偏離} \le +2.5\%$（鎖定回測下軌有撐開始回溫之標的）
  - 三大法人合計買超佔比 $\ge 1.0\%$ 且買超張數 $> 0$
  - 評分降序精選前 3~6 檔，標註 `[Tier-2 支撐回測候補]`，保證每日戰報品質與流動性。

### 2. 拒接飛刀：通道走平與K線止跌型態
- **通道防墜落開口**：距 20MA 中軌空間上限限制在 $6.5\%$ 內，且要求月線未大幅陡峭跳水，排除「沿下軌一路破底」之主跌浪。
- **實質落底K棒**：要求當日留下影線（$\ge 25\%$）或收紅K落底，拒絕大長黑飛刀。

### 3. 實戰四大防線 2.0 (Four-Price Standards 2.0)
- **🟢 進場價位 (Entry)**：當日收盤價為基準，次日開盤不破訊號日低點即建倉。
- **🔵 加碼價位 (Add-on)**：$\max(\text{當日高點}, \text{現價} \times 1.025)$，右側帶量突破加碼。
- **🔴 停利目標 (Take-Profit)**：
  - **TP1 (布林中軌 20MA)**：達到中軌時獲利了結 50%，並將剩餘部位之停損點拉升至進場成本價（啟動移動保本）。
  - **TP2 (布林上軌 UB)**：剩餘 50% 享受波段主升段利潤。
- **🛑 防禦型動態停損 (Stop-Loss)**：$\max(\text{下軌} \times 0.96, \text{訊號日低點} \times 0.99)$，訊號日低點為首要防守底線，截斷虧損。

## 專案檔案清單

```text

├── screener.py          # 盤後自動化選股器 V2.5 (支援 --line 與 --export)

├── result.md            # 視覺化字卡 Markdown 戰報
```

## 快速使用教學

### 一、Python 一鍵自動選股
```powershell
# 執行最新交易日選股 (自動支援 Tier-1/Tier-2 雙層降級)
python screener.py --export result.csv

# 自動推播至專屬 LINE 視窗
python screener.py --line
```

### 二、盤中即時雷達
```powershell
# 啟動盤中巡邏 (每 60 秒輪詢四大防線到價事件)
python intraday_scanner.py --interval 60

# 單次檢測
python intraday_scanner.py --once
```
