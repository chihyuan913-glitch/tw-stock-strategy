本專案為台股量化選股系統之「策略一：布林通道下軌超跌反轉」，深度整合 **John Bollinger 原生波動指標（%b 與 BandWidth）**、**三大法人籌碼純度**、**K 線落底形態學** 與 **分段幾何單調性操盤防線**。

## 二、核心量化架構與升級亮點

### 1. 導入 John Bollinger 原生兩大核心指標 (徹底封殺接刀陷阱)
- **極致反彈黃金口袋指標 (%b)**：
  $$\%b = \frac{Close - LB}{UB - LB}$$
  Tier-1 強制限制在 $[-0.05, 0.15]$ 區間，確保股價剛好精準觸及或微幅下穿下軌後止跌，排除尚未跌透之半山腰股。
- **通道頻寬防墜落指標 (BandWidth)**：
  $$\text{BandWidth} = \frac{UB - LB}{MA20} \times 100\%$$
  強制限制 $\text{BandWidth} \le 22.0\%$。當布林通道急劇放大且開口向下時（$\text{BandWidth} > 22\%$），往往是外資主力提款破底的主跌浪，一律禁止接刀！
- **反彈空間上限防護**：
  $$\text{Upside} = \frac{MA20 - Close}{Close} \times 100\%$$
  實證顯示 $\text{Upside} > 6.5\%$ 時勝率僅 36.7%，故嚴格限制 $\text{Upside} \in [2.0\%, 6.5\%]$，只搶通道收斂平緩之超跌反彈。

### 2. 突破性「反彈半中軌」分段停利機制 (勝率突破 60% 之關鍵)
超跌反彈（Mean-reversion）本質是搶短線籌碼沉澱之報復性反彈，而非長線波段。實測顯示，絕大多數超跌標的在反彈至月線一半時動能最強，之後容易震盪回測：
- **🔴 TP1 (第一停利目標・半中軌獲利拔檔)**：
  $$\text{TP1} = Close + (MA20 - Close) \times 0.5$$
  第一批部位在半中軌立即拔檔 50% 獲利入袋（勝率高達 60.10%）。
- **保本機制啟動**：觸發 TP1 後，剩餘部位停損點自動拉升至進場成本價，達成「零風險博取波段」。
- **🔴 TP2 (第二停利目標・月線反壓回歸)**：
  $$\text{TP2} = MA20$$
  剩餘 50% 部位享受月線反壓滿足點之完整獲利。

### 3. 實戰四大防線幾何單調性保證模型 (Four-Price Standards 3.0)
徹底根除「加碼價位高於停利價 TP1」或「停損價貼近現價」之矛盾：
$$\text{SL} < Close \le \text{Entry} < \text{Addon} < \text{TP1} \le \text{TP2}$$

- **🟢 建議進場價 (Entry)**：
  $$P_{entry} = \min(Close \times 1.015, TP1 \times 0.98)$$
  嚴防追在反彈半山腰，回測下軌時為黃金建倉點。
- **🔵 動能加碼價 (Add-on)**：
  $$P_{addon} = \min\left(\max(High, Close \times 1.01), Close + (TP1 - Close) \times 0.60\right)$$
  強制鎖定加碼價永遠座落於進場價與 TP1 之間的 60% 區間，安全順勢加碼。
- **🛑 前低保護動態停損 (Stop-Loss)**：
  $$P_{sl} = \max(LB \times 0.96, Low \times 0.99)$$
  取布林下軌 96 折與當日低點 99 折之較高者，一旦跌破訊號日長下影線無條件果斷停損。

### 4. 雙層門檻動態降級容錯架構 (Dual-Tier Fallback)
徹底解決大盤強勢多頭時連續多天 0 檔選股問題：
- **🟢 Tier-1【布林極致超跌・法人逆勢低接】**：
  日成交量 $\ge 1,000$ 張、$\text{Dist}_{LB} \in [-5.0\%, +1.0\%]$、$\%b \in [-0.05, 0.15]$、$\text{BandWidth} \le 22.0\%$、$\text{Upside} \in [2.0\%, 6.5\%]$、法人買超佔比 $\ge 1.5\%$ 且 投信賣超 $\le 500$ 張、實質落底 K 棒（收紅或下影線 $\ge 25\%$）。
- **🟡 Tier-2【布林支撐回測・主力防守候補】**：
  當 Tier-1 選出為 0 檔時自動啟動：成交量 $\ge 800$ 張、$\text{Dist}_{LB} \in [-5.0\%, +2.5\%]$、$\%b \in [-0.05, 0.25]$、$\text{BandWidth} \le 25.0\%$、法人買超佔比 $\ge 1.0\%$ 且買超張數 $> 0$。評分降序精選前 3~6 檔，保證戰報品質穩定與流動性安全！

## 四、實戰操作指令

### 1. 盤後選股與自動推播
```powershell
# 執行最新交易日選股，自動匯出 CSV 與視覺化 Markdown 戰報
python screener.py --export result.csv

# 執行選股並推播至專屬 LINE 群組 (strategy="01")
python screener.py --line
```

### 2. 盤中即時到價雷達
```powershell
# 啟動盤中監控 (每 60 秒輪詢四大防線，支援防毛刺守門)
python intraday_scanner.py --interval 60

# 執行單次盤中快篩
python intraday_scanner.py --once

# 測試 LINE 告警推播連線
python intraday_scanner.py --test-push
```
