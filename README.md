# 台股選股策略：布林通道下軌超跌 ＋ 三大主力法人逆勢買超

本專案提供完整的台股量化選股策略與自動化執行工具，整合**統計學波動通道**與**三大法人籌碼面**，專注於捕捉「散戶恐慌殺低、籌碼落入法人手中、超跌技術性反轉」的高勝率波段進場點。

---

## 策略設計核心理念

### 1. 為什麼日成交量大於 1,000 張？
- **流動性保護**：剔除成交量稀少的冷門殭屍股，避免買得到賣不掉的流動性折價風險。
- **指標有效性**：布林通道等統計指標在具備充足流動性的股票上，其統計分佈與標準差更為精準可信。
- **主力控盤度**：成交量大於 1,000 張代表有市場關注度與資金活水，一旦反彈具備足夠的向上推升力道。

### 2. 為什麼選「布林通道下軌 1% 或是跌破 5% 之內」？
- **統計學極端值**：布林通道（Bollinger Bands, 預設 20MA, $\pm 2\sigma$）涵蓋了常態分佈約 95.4% 的價格波動區間。當價格觸及下軌時，代表價格已處於統計學上的「極度超跌區」。
- **下軌 1% 位置**：表示股價回測下軌尋求強支撐，且尚未跌破，屬於標準的下軌反彈進場點。
- **跌破 5% 之內**：代表短線出現恐慌性洗盤、誘空或假跌破。若跌幅控制在 5% 以內，代表多方主力仍在防守；若跌破超過 5%，則布林通道恐向下打開「喇叭口」進入主跌段，此區間設定能精準過濾掉失控破底股。
- **數學量化定義**：
  $$\text{Bias}_{LB} = \frac{\text{Close} - \text{LowerBand}}{\text{LowerBand}} \times 100\%$$
  條件區間：$-5.0\% \le \text{Bias}_{LB} \le +1.0\%$

### 3. 為什麼要搭配「三大主力法人逆勢買超且未大量拋售」？
- **散戶恐慌 vs 法人吸籌**：當股價跌到布林下軌時，通常市場充斥利空消息，散戶紛紛停損殺低。此時三大法人若「逆勢買超」，代表大資金在低檔承接廉價籌碼（吃貨、造底）。
- **未大量拋售防護網**：避免表面上自營商避險微幅買超，但投信或外資實際上在大額倒貨停損的陷阱（本策略特別加入投信賣超嚴格限額，防範土洋對作的受災股）。

## 快速使用教學

### 一、Python 一鍵自動選股（免費、免登入、免 API Key）

直接在終端機執行：
```powershell
python screener.py
```

#### 進階指令參數：
```powershell
# 指定歷史日期（例如 20261006）並匯出 CSV
python screener.py --date 20261006 --export result.csv

# 提高量能門檻至 2000 張
python screener.py --min-vol 2000

# 嚴格要求下軌附近（下軌 -2% 到 +0.5%）
python screener.py --min-dist -2.0 --max-dist 0.5

# 匯出 Markdown 格式報表
python screener.py --export result.md
```

### 二、XQ 全球贏家（XS 語法）
1. 開啟 XQ 全球贏家軟體。
2. 點擊頂部選單「策略」→「選股中心」→「新增自訂策略」。
3. 腳本類型選擇「選股」，將 [`xq_strategy.xs`](./xq_strategy.xs) 內容完整複製貼上。
4. 設定執行頻率為「日線」，點擊「執行選股」即可於盤後或盤中一鍵篩選出符合個股。

### 三、TradingView（Pine Script v5）
1. 打開 TradingView 任意台股 K 線圖。
2. 點選下方「Pine Editor（Pine 編輯器）」。
3. 將 [`tradingview_strategy.pine`](./tradingview_strategy.pine) 代碼貼入並點擊「新增至圖表」。
4. 圖表上將自動標示出符合技術面下軌觸底的進場訊號三角形與背景色，並支援設定手機 App 推播快訊。

## 實戰交易操作 SOP

| 流程階段 | 操作重點與檢核項目 |
| :--- | :--- |
| **進場確認** | 1. 每日盤後執行 `screener.py` 或 XQ 產出清單。<br>2. 檢查個股 K 線：是否出現下影線、晨星、落底紅K？<br>3. 檢查布林通道：軌道是否走平（代表震盪打底），若上軌與下軌正在急劇向下擴散發散（開口向下）則應先觀望。<br>4. 優先挑選外資與投信合力買超（土洋同步）之標的。 |
| **停損風控（防守）** | 1. **硬性停損**：收盤價跌破進場當日最低價，或跌破下軌超過 5%（無條件出場）。<br>2. **籌碼變節**：次日三大法人反手大幅提款賣超。 |
| **停利離場（進攻）** | 1. **第一波反彈目標**：股價反彈至**布林通道中軌（20MA）**，出脫 1/2 持股入袋為安。<br>2. **第二波波段目標**：若強勢帶量突破中軌，續抱至**布林通道上軌**或跌破 5 日線全數出場。 |
